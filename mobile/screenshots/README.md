# Screenshots Directory

Place your captured screenshots in the appropriate folders:

## iOS Screenshots

### Required:
- `ios/6.7-inch/` - iPhone 15 Pro Max (1290 x 2796)
- `ios/6.5-inch/` - iPhone 14 Plus (1242 x 2688)

### Recommended:
- `ios/5.5-inch/` - iPhone 8 Plus (1242 x 2208)

## Android Screenshots

### Required:
- `android/phone/` - Phone screenshots (1080 x 1920)

## Naming Convention

Name your screenshots sequentially:

```
01-onboarding.png
02-dashboard.png
03-group-details.png
04-add-member.png
05-payment-requests.png
06-request-detail.png
```
